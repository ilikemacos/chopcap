Playground

Write Chopcap and run it, right here. Nothing is sent anywhere — this page carries a JavaScript build of Chopcap that runs in your browser, and it is checked against the same test suite as the real chopcap command.

What is different here

      
The playground runs in a browser tab, so two things behave differently from the real
        command: the files module is not available, and ask takes its
        answers from the box above instead of the keyboard. Everything else — including the
        error messages — is the same.

    


    

      
Handy while you are here

      
⌘⏎ or Ctrl+Enter runs the program.
        Tab inserts four spaces, which is the indentation Chopcap blocks
        expect. Long loops are stopped automatically so a runaway while cannot
        freeze the page.
