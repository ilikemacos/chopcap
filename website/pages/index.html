Chopcap

Programming without the clutter.

A very small language for people who want to write a program, not a ceremony. One binary, no dependencies, errors that read like a person wrote them, and a manual you can finish in an afternoon.

Small on purpose

    
Twenty-two keywords, seven built-in functions and six library modules.
      That is the whole language. There is nothing else to learn later.


    

      

        
::

        
Simple syntax

        
say prints, ask reads, fun defines.
          Indented blocks, no semicolons, no braces, no boilerplate around your first line.

      

      

        
→

        
Fast startup

        
A 110 KB native binary with no runtime to load. A .chop script
          starts in a couple of milliseconds, so it feels like a shell command.

      

      

        
!

        
Friendly errors

        
Never a stack trace. Every error names the file and line, shows the line, explains
          the problem in ordinary words, and often guesses what you meant.

      

      

        
◔

        
A tiny learning curve

        
The complete manual is one page. If you have written anything before, you will be
          writing useful Chopcap within about ten minutes.

      

      

        
⌘

        
macOS first

        
A one-command, checksum-verified install for both Apple Silicon and
          Intel. No package manager, no virtual environment, no project file.

      

      

        
{}

        
Open source

        
About 3,500 lines of dependency-free C11 you can read in a sitting, MIT licensed,
          with a test suite that runs with a single make test.

      

    

  






  

    
Errors that help

    
A beginner should never meet a stack trace. When Chopcap cannot run
      something, it says so the way a patient person would.

The language, by example

    
Six short programs that cover most of Chopcap. Every one of them runs
      exactly like this.

    say "excellent"

true

fun add(a, b):
    return a + b

fun fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

say add(5, 7)
say fact(6)

fun apply(f, v):
    return f(v)

say apply(fact, 4)

        

        

          
output

          
12
720
24

        

      

    


    

      

        

          
# Marks for a small class.
use lists
use math

scores = [72, 91, 64, 88, 95, 70]

fun average(values):
    return lists.sum(values) / len(values)

say "count  ", len(scores)
say "lowest ", lists.min(scores)
say "highest", lists.max(scores)
say "average", math.round(average(scores), 2)

passed = []
for s in scores:
    if s >= 75:
        push(passed, s)
say "passed ", passed

        

        

          
output

          
count   6
lowest  64
highest 95
average 80
passed  [91, 88, 95]

Install Chopcap

    
One command. It detects your chip, downloads the matching binary from
      GitHub Releases, checks its SHA-256 checksum, and installs a single file.


    

      $
      {{INSTALL}}
      
    


    

      

        
Then run something

        
chopcap hello.chop runs a program, and chopcap on its own
          opens the interactive prompt.

      

      
        
Other ways in

        
Download an archive by hand, pick your own install directory, or build from source
          with nothing but a C compiler.

      
      
        
Releases

        
Archives for arm64, x86_64 and a universal build, with
          published checksums.

      
    


    

      Prefer to read before you run? The installer is
      right here — it is a short,
      commented shell script that writes exactly one file.
