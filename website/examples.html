Example programs

Every program here is a real file in the repository, run by the test suite on every change. You can edit and run any of them right on this page — the playground uses a JavaScript build of Chopcap that is checked against the same tests as the chopcap command.

fizzbuzz.chop

Count to 20, but say Fizz, Buzz or FizzBuzz instead of some numbers.

greeting.chop

Ask a question, then use the answer.

guess.chop

A guessing game that reads your guesses from the keyboard.

hello.chop

The traditional first program.

notes.chop

Read and write files.

primes.chop

Find the prime numbers below 60.

shopping.chop

Working with lists.

temperature.chop

Convert temperatures and print a small table.

words.chop

Count the words in a piece of text.
